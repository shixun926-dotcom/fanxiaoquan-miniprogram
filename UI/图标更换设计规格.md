# 饭小圈 · UI 图标设计规格（最终版）

> 版本：V0.3（定稿，设计已锁定）
> 日期：2026-08-10
> 读者：小程序开发（后端零改动）
> 配套资产：`UI/icons/`（4 个 SVG 源文件 + 128/81 两档 PNG + 浏览器预览页）

---

## 1. 设计语言（已锁定）

整体方向：**暖橙 + 米白 + 食物黄 + 少量绿色**，传递"温暖、轻松、年轻、生活化"。明确不使用纯蓝科技风。

统一用色原则：**不给每个图标各配一套颜色**，所有图标从同一套色板取色，保证四个图标是一个设计系统，而非四个 App。

## 2. 核心色板（开发对齐用）

| 用途 | 名称 | 色值 | 说明 |

色彩语义分层：

```
饭小圈
├── 品牌色 #FF8A1F ── 生活 / 互动（我的主页、意见反馈、我的反馈）
├── 食物色 #FFC857 + #FFF9F0 ── 饭碗 / 餐具 / 背景
├── 情绪色 #FF8B72 ── 爱心
└── 功能色 #73B84B ── 决定 / 状态（决定图标、我的反馈中的"已处理"）
```

## 3. 四个图标（规格已锁定）

| 功能 | 核心图形 | 主色 | 辅助色 | 源文件 | PNG |
| --- | --- | --- | --- | --- | --- |
| 我的主页 | 人 + 小饭碗（含爱心） | `#FF8A1F` | `#FFC857` | `my-home.svg` | `my-home-128.png` / `my-home-81.png` |
| 决定 | 绿色圆圈 + ✓ + 小饭碗 | `#73B84B` | `#FFC857` | `decide.svg` | `decide-128.png` / `decide-81.png` |
| 意见反馈 | 本子 + 铅笔 + 对话框 | `#FF8A1F` | `#FFC857` | `feedback.svg` | `feedback-128.png` / `feedback-81.png` |
| 我的反馈 | 记录本 + 放大镜 + 小饭碗 | `#FF8A1F` | `#73B84B` | `my-feedback.svg` | `my-feedback-128.png` / `my-feedback-81.png` |

### 3.1 我的主页（my-home）

结构：① 米白圆角背景 → ② 橙色人物（头 + 肩部圆弧，深橙描边）→ ③ 右下角小饭碗（食物黄 + 米饭白高光）→ ④ 饭碗内爱心（腮红粉）。语义：**"我 + 吃饭"**。

### 3.2 决定（decide）

结构：浅绿圆底 + 深绿描边圆圈 → 深绿 ✓（大勾）→ 右下角小饭碗。语义：✓ 天然关联"确定 / 完成 / 选择 / 已决定"，所以决定功能用**绿色**而非橙色。

### 3.3 意见反馈（feedback）

结构：米饭白本子（深橙描边 + 三行文字）→ 斜跨铅笔（食物黄笔身、品牌橙笔尖）→ 右下角品牌橙对话框（含三点深棕文字）。语义：**本子=意见、铅笔=输入、气泡=沟通**。

### 3.4 我的反馈（my-feedback）

结构：米饭白记录本（品牌橙边框 + 食物黄夹子）→ 三行状态（绿 ✓ 已处理 / 橙黄 ◷ 处理中 / 灰 ••• 待处理）→ 放大镜（深橙，=查询）→ 左下角小饭碗。语义：**记录 + 状态 + 查询**；图标内状态色与业务状态一一对应。

## 4. 图标资源规格

| 项 | 规范 |
| --- | --- |
| 源格式 | SVG（`viewBox="0 0 128 128"`，矢量可无损缩放） |
| 位图格式 | PNG，RGBA 透明外（图标自带米白圆角底） |
| 尺寸 | 128 × 128（Dock / 入口用，保证 2x 清晰）；81 × 81（原生 tabBar 兜底用） |
| 描边 | 统一 3–4px（128 基准），视觉粗细一致 |
| 主色纪律 | 只有「决定」用绿色系；其余三个一律品牌橙系（辅以食物黄） |

## 5. 落地到小程序（精确到文件与代码）

### 5.1 建议替换位置

| 图标 | 落地位置 | 现状 |
| --- | --- | --- |
| 我的主页 | Dock「我的」tab | emoji `👤`（`custom-tab-bar/index.js`）→ 换 `my-home-128.png` |
| 决定 | Dock「决定」tab | emoji `🎡` → 换 `decide-128.png` |
| 意见反馈 | 我的页「意见反馈」入口 | 当前 emoji / 无图标 → 加 `feedback-128.png` |
| 我的反馈 | 我的页「我的反馈」入口 | 当前 emoji / 无图标 → 加 `my-feedback-128.png` |
| 饭小圈 | Dock「饭小圈」tab | 品牌图 `logo-128.png`，**默认保留**（本套图标不含饭小圈） |

### 5.2 Dock 代码（`custom-tab-bar/index.js`）

```js
list: [
  { pagePath: '/pages/feed/feed',  text: '饭小圈', iconType: 'img', iconSrc: '/images/brand/logo-128.png' },
  { pagePath: '/pages/decide/decide', text: '决定', iconType: 'img', iconSrc: '/images/brand/decide-128.png' },
  { pagePath: '/pages/profile/profile', text: '我的', iconType: 'img', iconSrc: '/images/brand/my-home-128.png' }
]
```

即将两个新 PNG 拷贝到 `images/brand/` 后替换引用即可（或把 4 张图统一放 `images/icons/`，改 `iconSrc` 路径）。

### 5.3 原生 tabBar 兜底（`images/tabbar/`）

- `decide.png` / `decide-on.png` ← `decide-81.png`（81 档）
- `profile.png` / `profile-on.png` ← `my-home-81.png`
- `feed.png` / `feed-on.png` 保留（饭碗与"饭小圈"语义一致）
- 若原生兜底不常显示（`custom: true`），此步可延后。

### 5.4 状态色约定（业务联动）

"我的反馈"列表 / 详情页的**状态徽章**请沿用图标内色值：已处理 `#73B84B`、处理中 `#FFB020`、待处理 `#A8A19A`，做到图标色与业务状态一一对应。

### 5.5 后端

零改动。

## 6. 验收清单

- 四个图标在 Dock 与我的页入口正确显示，无白边、无变形、清晰。
- 「决定」用绿色系、「我的主页 / 意见反馈 / 我的反馈」用橙色系，色板统一。
- 切换 tab 选中态（Dock 橙红渐变胶囊）下图标清晰可辨；若「决定」绿图标在橙色选中底上观感不佳，由设计确认微调（如选中态加深图标外描边）。
- 81 × 81 兜底图标替换后未选中 / 选中态正确。
- 真机预览与 `UI/icons/preview.html` 效果一致。
