## 1. 需求背景

菜品图已由绘图兄弟按 `UI/Foods.md` 的 200 道菜逐一出图（菜品无任何改动），随后将上传到阿里云 OSS。当前小程序里所有菜品 / 分类相关位置都是 **emoji 回显**（盲盒揭晓、结果弹层、收藏、历史、帖子占位图、用户主页作品、分类 chips）。客户要求：**所有回显 emoji 的地方，改为回显对应菜品的图片**。

设计原则：**emoji → 图片只发生在展示层**，数据模型与云函数尽量零改动；菜品图 URL 由前端统一映射，避免 200 张图的路径散落各处。

## 4. 前端映射方案（云函数零改动）

### 4.1 映射层：扩展 `utils/mock.js`（配套文件 `UI/dishes-img.js`）

已生成可直接复制的映射文件 **`UI/dishes-img.js`**（由脚本从 `Foods.md` 自动生成，200 项零手抄），内容即：

```js
// 1) OSS 菜品图基址（与 utils/oss.js 的 bucket 一致）
const DISH_IMG_BASE = 'https://fanxiaoquan.oss-cn-beijing.aliyuncs.com/dishes'
const DISH_IMG_NUM = {  // dish 名 -> Foods.md 序号
  '重庆老火锅': 1, '九宫格火锅': 2, /* … 共 200 项 */ '锅盔': 200
}

// 2) 取图函数：返回图片 URL；未匹配到则回退空（前端显示兜底）
function getDishImage(dish) {
  const n = DISH_IMG_NUM[dish]
  return n ? DISH_IMG_BASE + '/dish_' + String(n).padStart(3, '0') + '.png' : ''
}

module.exports = { DISH_IMG_BASE, DISH_IMG_NUM, getDishImage }
```

- 将 `dishes-img.js` 复制到 `utils/` 并在页面 `require` 使用；或把两段内容并入 `utils/mock.js` 导出。
- 已确认采用**序号命名**，无需备选方案分支。

### 4.2 数据透传（前端统一补 `img` 字段）

各页面拿到数据后，在 `setData` 前为每条记录补 `img`：

| 数据 | 现状字段 | 补字段 |
| --- | --- | --- |
| 盲盒揭晓 `reveal` | `{dish, category, emoji}` | `reveal.img = getDishImage(dish)` |
| 结果弹层 `popup` | `{dish, category, emoji}` | `popup.img = getDishImage(dish)` |
| 帖子列表 `posts` | 每条含 `dish` | 每条 `img = getDishImage(dish)`（用于无 `imageUrl` 占位） |
| 收藏 `favorites` | 每条含 `dish` | 每条 `img` |
| 历史 `history` | 每条含 `dish` | 每条 `img` |
| 用户主页作品 `works` | 每条含 `dish` | 每条 `img` |

> 所有补字段都在**前端**完成，云函数返回结构不动 → 老数据（已存的收藏 / 历史 / 帖子）无需迁移，天然兼容。

### 4.3 展示层（WXML 改造）

每个回显点把 `<text class="xx-emoji">{{x.emoji}}</text>` 改为图片，并保留兜底：

```xml
<image wx:if="{{x.img}}" class="xx-img" src="{{x.img}}" mode="aspectFill"
       binderror="onImgError" data-key="dish" />
<text wx:else class="xx-emoji">{{x.emoji}}</text>
```

- `binderror` 统一处理：图片加载失败（404 / 网络）时隐藏图片、回退 emoji（见 §5）。
- 帖子占位图（E3）：`imageUrl`（用户上传图）优先；无上传图时用菜品图 `img`；菜品图也失败回退 emoji（现状逻辑上多一层）。

## 5. 兜底与异常

| 异常 | 处理 |
| --- | --- |
| 菜品图未上传 / 上传中 | `getDishImage` 命中但请求 404 → `binderror` 回退 emoji（保持现体验） |
| 非 200 道目录内的新菜 / 用户自定义菜名 | `DISH_IMG_NUM` 查不到 → 无 `img` → 直接用 emoji 兜底 |
| 图片加载慢 | `<image>` 自带渐进加载；列表懒加载（`lazy-load`） |
| 域名未配置 | 上线需在小程序后台添加 `downloadFile` 合法域名：`https://fanxiaoquan.oss-cn-beijing.aliyuncs.com`（原型 `urlCheck:false` 不受限） |
| 老数据 | 无迁移；前端按 `dish` 实时映射，存量收藏 / 历史 / 帖子自动生效 |
